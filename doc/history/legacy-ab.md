# AB 测试：v2（MNA 生成）vs legacy（手推 WDF）

> 归档：2026-10-29。一次性实验记录，不再更新。
> 完整原始记录（13 条经验、FFT 判读细节、台架参数）在
> rustomp 仓 `docs/history/ab-test-sparklin-v2.md`；当前验证数字见
> [`../current/architecture.md`](../current/architecture.md)。
>
> 时间：2026-10-25 ｜ 参与者：用户（听感 / 信号源 / FFT 截图）+ 助手（指标 / 台架复现 / 修复）
> 一句话结论：**"听起来差不多"和"算对了"之间，隔着一次 AB 测试和两个真 bug。**

---

## 1. 为什么要做

`v0.1.0` 第一次用**全生成链路**（网表 → 电路代码；toml → 插件外壳）产出了 v2。
数字很好看：THD 27.65 %、h2–h9 与 ngspice 逐次差 ≤0.03 pp、直流工作点差 0.06 mV。

但这些都是**同一条实现上的自证**。真正的问题是：换一条完全不同的数值路径
（通用 MNA + 定点迭代 vs 手推 WDF + 收敛判据），声音还是同一台机器吗？

## 2. 装置

| 项 | 做法 |
|---|---|
| 宿主 | Logic Pro，单声道音轨 |
| 两个身份 | `Sparklin Drive Mono`（v2）/ `Sparklin Drive Legacy Mono`（legacy 改成独立身份，不动 DSP） |
| 参数对齐 | Gain / Level 都在 50 %（映射同为 0..1 → 0..500k） |
| 延迟对齐 | 两者都是 15 样本，避免梳状滤波造成"厚薄"错觉 |
| 客观 | 880 Hz / 1 kHz 正弦与方波 + 频谱分析；离线台架复算 |
| 主观 | 真实吉他：单音 / 和弦 / 重拨 / 轻拨 |

## 3. 结果

第一轮用户反馈：**"音色取向相同，但新版高频更毛更亮，混入浑浊刺耳成分，有数字味。"**

台架复现后定位到两个真 bug：

| bug | 现象 | 根因 | 修法 |
|---|---|---|---|
| **次谐波极限环** | 方波基频以下出现 +12~+19 dB 隆起；正弦完全看不出来 | `step_fixed` 固定 2 次牛顿迭代，快速边沿欠收敛 | 迭代次数成为网表指令 `newton=`（本插件用 4），加"方波次谐波 < −60 dB"回归测试 |
| **电位器端点静音** | Level 拧到 100 % 没声，99 % 正常 | `500k·(1−t)` 在 t=1 时得 0 Ω → 导纳 g=∞ → 矩阵 NaN → 熔断静音 | 框架在**唯一装配入口**把电阻夹到 `MIN_RESISTANCE = 1 mΩ`，加 8 个端点组合的回归测试 |

修复后：

| 指标 | legacy（WDF） | v2 修复前（2 次迭代） | v2 修复后（4 次迭代） |
|---|---|---|---|
| 方波次谐波 | −70 dB | **+19 dB** | −70 dB |
| THD @0.2 V | 27.650 % | 27.65 % | **27.579 %**（ngspice 27.5682 %） |
| 高频（9 kHz 以上） | 基准 | 高 2–4 dB | **低 2–4 dB** |
| 48k 单声道 CPU | — | ~20 % | ~36 % |

**最终差异**：THD 差 **0.08 pp**，主观 **"A/B 无可感差别"**；9 kHz 以上 2–4 dB 的差是
两种积分方法的真实差异（legacy 梯形法的半样本延迟在极高次谐波"多给"了一点），不是 bug。

## 4. 留下的教训

1. **测试信号要分层**：正弦只管稳态谐波，查不出求解器欠收敛；必须有方波 / 阶跃这一层，
   再加真实乐器这一层。只有正弦 = 只验了一半。
2. **THD 通过 ≠ 算对了**：要专门验"不该出现的分量"（次谐波、非谐波杂散、DC 漂移、NaN 计数）。
3. **把听感形容词翻译成指标**：高频更毛 → 10–18 kHz +2–4 dB；浑浊数字味 → 基频以下次谐波 +19 dB。
   "多了不该有的东西"是 bug，"某个东西多一点"才是调音。
4. **迭代次数是正确性参数，不是性能参数**：可以量化地拿 2 倍 CPU 换回正确性。
5. **参数端点是 bug 的温床**：凡"由参数算元件值"，先问 t=0 / t=1 时等于几；修复放在最底层单一入口。
6. **熔断是止损不是修复**，必须配"数非有限值"这类可观测性，否则问题会一直藏着。

## 5. legacy 的现状

`sparklin-drive-legacy` 已**冻结**，只作为 AB 基线保留：

| | 本仓（v2） | legacy |
|---|---|---|
| 引擎 | rustomp MNA（通用装配器） | 手推 WDF（一次性实现） |
| 电路来源 | 网表 → 代码生成 | 手写 Rust |
| 状态 | **活跃** | 冻结归档 |
